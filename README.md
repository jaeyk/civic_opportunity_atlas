# Civic Opportunity Atlas

Live site: https://jaeyk.github.io/civic_opportunity_atlas/

A static web tool, in development, for civic engagement that meets people where they are.

## Who it's for

| Audience | What they're trying to do | What the tool gives them |
|---|---|---|
| 🌱 **Foundations** | Decide where and how to invest in civic life | Places compared with similar places; profiles of a grant region or portfolio; exports for proposals and board decks |
| 🎓 **Universities** | Build community partnerships and engagement | A profile of the area around campus; which kinds of organizations offer which opportunities nearby; briefs for engagement reports |
| 🏛️ **State and local governments** | Plan civic engagement strategy (e.g., a civic engagement office) | Every county or ZIP code in the jurisdiction, compared with peers and with poverty, broadband and education; GIS exports |
| 📣 **Organizers** | Understand their community and bring others into the conversation | A plain-language profile of their place, a printable version, and a QR code for flyers |

🏘️ **Community members** are who these audiences engage. The tool reaches them through shared links, QR codes, and printed profiles that work on a phone or on paper.

## What it does

1. **Learn** how civic opportunity is structured in their county and ZIP code: what kinds of opportunity exist (membership, volunteering, public events, civic and political action), to what extent, and which kinds of organizations provide them.
2. **Compare** with similar places, through plain-language observations that state how confident the data lets us be.
3. **Start conversations**: printable profiles, QR codes, and discussion questions built from each place's own findings.

It is built on the MapAgora datasets from the [SNF Agora Institute](https://snfagora.jhu.edu/) at Johns Hopkins University.

> The earlier Quarto/R teaching dashboard and the Flask "Civic Quest" prototype are preserved on the `archive/quarto-dashboard` branch (tag `quarto-dashboard-final`).

## Repository layout

| Path | Contents |
|------|----------|
| `raw_data/` | County-level MapAgora data, county classifications (USDA RUCC), county/state boundaries |
| `raw_data/mapagora_full/` | Organization- and ZIP-level MapAgora data. Not in git; run `./get_full_data.sh` |
| `data/derived/` | Derived files from the prototype: county lookup, centroids, GeoJSON, Civic Quest JSON |
| `pipeline/` | Python data pipeline: opportunity × organization-type counts, smoothed rates, peer places, clusters |
| `data/processed/` | Pipeline output (parquet). Not in git; run `python -m pipeline.build` |
| `tests/` | Pipeline and site-text tests |
| `docs/` | The website (served by GitHub Pages). Pages and scripts are hand-written; `docs/data/` is generated by `python -m pipeline.site_data` |
| `preview.sh` | Preview the website locally |
| `misc/` | Source paper: Kim, de Vries & Han (2025), *Scientific Data* |

## Setup

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
./get_full_data.sh                      # org- and ZIP-level data (~55 MB)
.venv/bin/python -m pipeline.build      # writes data/processed/ (~1 min)
.venv/bin/python -m pipeline.site_data  # writes docs/data/ for the website (~1 min)
.venv/bin/python -m pytest tests
./preview.sh                            # open the website at http://localhost:8000
```

## Publishing

GitHub Pages serves the `docs/` folder on `main` (Settings → Pages → Deploy from a branch → `main` / `/docs`). To publish changes: rebuild if the data changed, commit `docs/`, and push to `main`. There is no GitHub Actions workflow.

```bash
./preview.sh --build                    # rebuild everything and preview
```

## Data

- **Full data:** [Harvard Dataverse, doi:10.7910/DVN/IRCA7C](https://doi.org/10.7910/DVN/IRCA7C) (CC0)
- **Data paper:** Kim, J.Y., de Vries, M., & Han, H. (2025). [MapAgora, civic opportunity datasets for the study of American local politics and public policy](https://www.nature.com/articles/s41597-025-05353-6). *Scientific Data* 12:1162.
- **Empirical paper:** de Vries, M., Kim, J.Y., & Han, H. (2024). [The unequal landscape of civic opportunity in America](https://doi.org/10.1038/s41562-023-01743-1). *Nature Human Behaviour* 8, 256–263.

Organization records are de-identified. There are no names, EINs or street addresses; the finest location is the ZIP code.

**Other sources used by the site**

- Population and community conditions: U.S. Census Bureau, [American Community Survey](https://www.census.gov/programs-surveys/acs) 2017–2021 5-year estimates (included in MapAgora)
- Metro / small town / rural: USDA Economic Research Service, [Rural-Urban Continuum Codes](https://www.ers.usda.gov/data-products/rural-urban-continuum-codes/) (2013), `raw_data/County_Classifications.csv`
- ZIP-to-county assignment: U.S. Census Bureau, [2020 ZCTA-to-county relationship file](https://www.census.gov/geographies/reference-files/time-series/geo/relationship-files.2020.html)
- Boundaries (pipeline only): U.S. Census Bureau [cartographic boundary files](https://www.census.gov/geographies/mapping-files/time-series/geo/cartographic-boundary.html) for counties, states, and 2020 ZCTAs
- QR codes: [qrcode.js](https://github.com/davidshimjs/qrcodejs) (MIT License)
- Colors: "Smith" palette from [MoMAColors](https://github.com/BlakeRMills/MoMAColors) by Blake R. Mills (MIT License)
- Maps: [D3](https://d3js.org) (ISC License)
